Подпись релиза fuckgram

Работает без интернета, ключ не покидает этот компьютер. Клиент ставит обновление, только если подпись архива сходится.

1. Ключ (один раз)

Создаёт файл ключа, зашифрованный паролем. Храните файл и пароль только у себя, сделайте копию на флешку. Потеряете — следующую версию придётся ставить вручную.

2. Подписать архив релиза

Получится файл «имя архива.sig». Перетащите его в черновик релиза на GitHub (Edit → поле для файлов), затем Publish release.

3. Проверить

Архив и .sig сверяются с открытым ключом из файла ключа (пароль не нужен).
